# Smooth Top-Down Player Movement (Xogot Tutorial)

This project demonstrates how to build smooth, responsive **top-down player movement** entirely in **Xogot** — the iPad and iPhone port of the Godot game engine.

This tutorial shows how to create a clean and efficient top-down controller in **under 15 lines of code**, using linear interpolation for precise, fluid motion.

---

## Features

- Simple **CharacterBody2D** setup with sprite and collision shapes  
- Smooth directional movement using **linear interpolation (`lerp()`)**  
- Fully customizable speed and responsiveness  
- Minimal code — easy to extend for RPGs, shooters, or exploration games  
- Works directly on **iPad and iPhone** via Xogot  
- Compatible with **Godot 4.x**

## How to Use

1. Download or clone this repository:
   ```bash
   git clone https://github.com/xogot-projects/Xogot-Topdown-Movement.git

2. Or [download the ZIP directly](https://github.com/xogot-projects/Xogot-Topdown-Movement/archive/refs/heads/main.zip).

3. Open the project in [Xogot](https://apps.apple.com/us/app/xogot-make-games-anywhere/id6469385251) on iPad or iPhone.

4. Run the main scene to explore the movement system, or open `player.gd` to review the implementation.
